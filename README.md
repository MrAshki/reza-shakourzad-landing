# Reza Shakourzad Landing

A Persian, right-to-left landing page for an educational website by **Reza Shakourzad**. The page introduces two learning paths — **Artificial Intelligence** and **Mathematics** — with a cinematic dark visual system, interactive Three.js background, motion-driven hero section, and animated path cards.

> **Current scope:** this repository contains the landing page only. Assessment pages, authentication, backend APIs, database, dashboard, payment, and admin panels are not implemented yet.

## Where Processing Happens

| Area | Where It Runs | Notes |
|---|---|---|
| Static page rendering/build output | Server/build environment | Generated by `npm run build` |
| UI interactions | User browser | Navigation, CTA clicks, scroll behavior, header fade |
| Three.js background | User browser / client GPU | WebGL animation runs on the visitor’s device |
| Card Three.js scenes | User browser / client GPU | AI network and math symbols render inside the cards |
| Backend logic | Not present | No API/database/auth exists in this version |
| Assessment logic | Not present | Routes are placeholders for a future phase |

Because the Three.js scenes run on the client, the hosting server does not need heavy CPU/GPU resources. Smoothness depends mostly on the visitor’s browser, GPU, and device age.

## Minimum Client Device Recommendation

The site should be tested on the real target audience devices before public launch. Practical recommendations:

| Level | Suggested Device Capability |
|---|---|
| Minimum usable | Modern browser with WebGL enabled, 4 GB RAM, recent dual-core CPU, integrated GPU |
| Recommended desktop/laptop | 8 GB RAM, quad-core CPU, modern integrated GPU or dedicated GPU |
| Minimum mobile | Modern iOS/Android browser, WebGL enabled, 3–4 GB RAM |
| Recommended mobile | iPhone XS/XR or newer, or Android mid-range 2019+ / Snapdragon 730-class or better |

On weaker devices, the page should still load, but animation smoothness may drop and battery usage may increase.

## Server / Hosting Recommendation

This is currently a frontend landing page. It does not need a database server or backend application server unless new product features are added later.

| Hosting Option | Recommendation |
|---|---|
| Cloudflare | Good fit because the project already includes Cloudflare-related tooling. A final deploy script/config may still be needed. |
| VPS with Node.js | Works with Node.js `>=22.13.0`, ideally behind Nginx or Caddy with HTTPS enabled. |
| Managed frontend platforms | Possible, but should be tested with the Vinext/Vite setup before final selection. |

Suggested starting server for low-to-medium traffic:

| Resource | Minimum Practical Value |
|---|---:|
| CPU | 1 vCPU |
| RAM | 1 GB |
| Storage | SSD |
| Node.js | `>=22.13.0` |
| Network | HTTPS + CDN recommended |
| Compression | gzip or Brotli recommended |

More comfortable production baseline:

| Resource | Recommended Value |
|---|---:|
| CPU | 2 vCPU |
| RAM | 2 GB |
| Node.js | `>=22.13.0` |
| Reverse proxy | Nginx or Caddy if using VPS |
| CDN | Recommended |
