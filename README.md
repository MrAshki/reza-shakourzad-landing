# لندینگ رضا شکورزاد

صفحهٔ اصلی RTL برای انتخاب یکی از دو مسیر یادگیری «هوش مصنوعی» و «ریاضی».

## اجرا

```bash
npm install
npm run dev
```

## بررسی کیفیت

```bash
npm run format
npm run lint
npm run type-check
npm run build
npm test
```

این پروژه فقط صفحهٔ لندینگ را پیاده‌سازی می‌کند. مسیرهای
`/assessment?path=ai` و `/assessment?path=math` صرفاً مقصدهای رزروشده‌اند و
صفحهٔ ارزیابی، احراز هویت، داشبورد، API یا پایگاه داده‌ای در این پروژه وجود ندارد.
